# V0.8.0 release staging

This directory will contain the validated public V0.8.0 release artifacts.

Expected user-facing artifacts:

- UB3 Control firmware for the lower 1541 ROM socket;
- UB4 passive Monitor firmware for the upper 1541 ROM socket;
- 1541HUD Windows executable;
- C64 OneROM configurator release;
- SHA-256 checksums, flashing instructions, wiring notes, and configuration
  examples.

Do not add an artifact until its board role, socket position, hardware result,
and checksum have been recorded.
