# Security Policy

## Supported scope

This repository distributes evaluation firmware, binaries, and documentation
for vintage-hardware modification. The current `v8.0` branch is not a signed
production release; see `docs/RELEASE_VERIFICATION.md` before using an artifact.

## Reporting a vulnerability

Do not publish potentially exploitable firmware, supply-chain, or hardware
safety details in a public issue before the maintainer has had a chance to
assess them. Use the repository owner's GitHub contact method and include the
affected artifact name, SHA-256, hardware configuration, reproduction steps,
and observed impact. Do not attach private ROM images, serial identifiers, or
hardware logs.
